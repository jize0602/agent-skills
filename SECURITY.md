# Security Policy

This repository is intended for public distribution. Keep it limited to reusable skill instructions, supporting resources, and generic project records. Never add API keys, tokens, passwords, private keys, authenticated browser state, customer data, private project facts, or unrelated private source code.

CI scans the current checkout and reachable history with the continuity security script. A clean scan is not a guarantee that all sensitive content has been detected; review findings and repository history before publication. Do not print matched secret values in reports.

GitHub access must use an authorized official connector or Git CLI. Browser sign-in alone does not establish that connection. The user completes any required official authorization personally; keep the pending operation intent and resume after authorization. Do not request credentials in chat or use browser state as a substitute.

The workflow grants `contents: read` and does not deploy, publish, or access external secrets. Local current-tree scan passed for this candidate; history scan and public CI are pending until the reviewed source is committed and checked remotely.
