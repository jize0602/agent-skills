# Lessons

## 2026-09-23

- Test fixtures containing literal credential-looking strings can block a public repository scan. Preserve the scanner tests while constructing synthetic examples at runtime; never suppress or weaken the scanner to make CI green.
- GitHub App repository listings can omit inaccessible repositories even after full pagination. Do not use listing absence or private 404 alone to justify creation.
- An integrity manifest generated by the same repository does not independently authenticate its publisher. Pin the official repository and release commit first.
